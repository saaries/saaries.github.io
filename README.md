# saaries.github.io

Personal website for Xinyan Li, built with Jekyll and hosted on GitHub Pages.

## Content

- `index.md` contains the homepage content.
- `_config.yml` contains site metadata, profile links, and navigation.
- `_layouts/default.html` contains the shared page shell and SEO metadata.
- `_sass/_style.scss` contains the responsive visual system.
- `resume.pdf` is the résumé linked from the site.

GitHub Pages builds the site automatically from the default branch.
